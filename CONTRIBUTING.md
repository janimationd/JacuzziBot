# Contributing

Thanks for your interest in contributing!

This project is shared under a source-available, noncommercial license. Contributions are welcome, but please read this document together with the LICENSE file.

## What’s encouraged
- Bug fixes
- Quality-of-life improvements
- New features that align with the project’s direction
- Refactors and cleanup
- Private forks for testing or experimentation

## What’s not allowed
- Using this code or Contributions to run or develop a competing Discord bot
- Commercial use of the code without permission

## Contributions and Ownership

- You retain copyright to your original Contributions
- By submitting a Contribution, you agree that:
  - It is licensed under the project’s LICENSE
  - Its use is subject to all restrictions in that license, including noncommercial and non-competing use restrictions
- These license terms apply **regardless of authorship**

For clarity, submitting a Contribution does **not** grant permission to reuse that Contribution in competing projects, even if you are the original author.

If you are unsure whether a change qualifies as a Contribution or whether an intended use is allowed, please ask before proceeding.
